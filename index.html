Steps to Improve My Web Skills

The realistic action plan I am following to advance my technical capabilities:

  1. Consistent Coding Practice: Dedicate 45 minutes each day to writing clean, valid HTML5 and hand-coded CSS layouts.
  2. Project-Based Building: Develop functional front-end mini-projects and track revision history using Git and GitHub.
  3. Standards & Accessibility Study: Regularly consult the MDN Web Docs reference to implement responsive design patterns and web accessibility best practices.

My Learning Plan

Three steps I follow every week while learning and practising web technologies:

  1. Learn the concept: Read the MDN page or lecture notes and note down the three most important points.
  2. Build something small: Re-create the example in a scratch file, then adapt it to this website.
  3. Review and commit: Check the page at mobile and desktop widths, fix any console errors, and push the work to GitHub with a clear message.
